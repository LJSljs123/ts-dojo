# TSOJ v3.0 PRD：时序预测研究工作台

> 原始需求：对整个项目前端可视化进行升级，以及内容也做成最顶级的最全的。
> 状态：范围建议稿｜内容核查日期：2026-10-24｜边界：纯静态、零依赖、零构建、经典 script、`file://` 可用。
> 已核实基线：15 道可判题、9 条确定性合成数据、29 张方法卡、方法库/路径/排行/提交详情；沿用既有判题和存储能力。

## 1. 产品定义

| 项目 | 内容 |
|---|---|
| 产品目标 G1 | 用统一设计系统把“看数据—选方法—回测—诊断—练习—复盘”串成可重复的研究闭环，而非换皮。 |
| 产品目标 G2 | 将卡片升级为 8 模块学科地图：每个核心概念有解释、演示、练习和可核查来源，明确可运行/概念级边界。 |
| 产品目标 G3 | 达到顶级数据产品的可用性：深浅色、响应式、键盘、低动态、可解释图表、可靠反馈，并维持离线交付。 |
| 核心指标 | 8 模块全部可达且先修/练习闭环；P0 实验可保存配置；375/768/1440 无横向溢出；既有判题与路由回归不退化。 |
| 非目标 | 不做账户/云同步/真实在线排行；不训练或下载基础模型；不做任意 Python/R 执行、实时数据接入、自动调参平台、论文全文百科或 SOTA 榜单。 |
| 产品原则 | 先可靠基线与评估，再复杂模型；先诚实的不确定性，再漂亮曲线；不以单窗口误差宣称方法优劣。 |

### 1.1 目标用户

- **入门学习者**：会基础编程但不了解时序，需可跟随路径和即时反馈。
- **算法/数据从业者**：需要比较基线、检查残差、选择验证方案并沟通业务风险。
- **高校师生/竞赛选手**：需要可复现实验、方法脉络、公式一致性和权威出处。
- **高阶研究者**：用概念地图定位方向；平台不承诺替代专业训练框架。

### 1.2 五条核心用户旅程

| 旅程 | 主路径 | 成功标准 |
|---|---|---|
| 新手入门 | 仪表盘→诊断当前水平→模块 1→观察季节分解→完成 p1–p3→看复盘 | 能从“为何用季节朴素”解释到误差结果，而非只复制题解。 |
| 方法研究 | 课程/方法库→方法详情→查看适用/限制/出处→带预设进入实验室→回测 | 同一数据、切分、horizon、指标下公平比较并保存配置。 |
| 诊断纠错 | 实验结果→预测/区间/残差/ACF→定位结构残留→调整参数→再次回测 | 新旧配置与指标变化可见；不会把测试集反复调参称作泛化提升。 |
| 课程进阶 | 路径图→满足先修→完成概念检查/练习→产出实验报告摘要 | 8 模块形成入口到业务实践的闭环，概念级内容不被误认为已实操。 |
| 移动复盘 | 375px 打开提交详情/课程→键盘或触控切换图表→继续对应练习 | 内容不溢出，图表摘要可读，草稿/既有进度不丢。 |

## 7. 题目策略与标定门禁

### 7.1 P0 不建议新增的题型

- 需要真实深度网络训练/反向传播、GPU、外部权重或多变量大数据的“伪基础模型题”。
- 靠随机搜索、固定测试点常数、硬编码答案或特定种子过拟合才能 AC 的题。
- 仅靠 MAPE 且含零值、仅凭单窗口排名、无限状态空间自动调参、开放式业务论述自动判分题。
- 复杂 ARIMA/MinT/概率分布全家桶工程题：更适合受控实验或 P1 专项，不为“全”强行扩题。

### 7.2 若后续新增题目，必须同时过门

1. **参考解 AC**：所有测试点有限、输出长度正确、确定性、无越权 API；得分建议 78–96，且不是通过硬编码获得。
2. **模板 WA**：原样 starter 不 RE/TLE、不通过；题目说明、输入输出、horizon 与边界用例一致。
3. **每条配置基线 WA**：不是只跑最优基线；`naive/seasonal_naive/mean/linear_trend/moving_average` 等凡列入该题均逐个提交且 `passed=false`。
4. **标定留痕**：逐点记录 yourMetric、各基线、ratio、threshold、score；阈值来自最差参考 ratio 加安全余量，不能拍脑袋。
5. **教学有效性**：数据形态确能体现方法；短序列/常数/零值/缺失等边界有定义；另以时间置换或错误实现反证门槛不会被无结构提交轻易越过。
6. **公平与回归**：训练只用 origin 前数据；不同 horizon/窗口均验证；既有 15 题 AC/WA、基线门禁和全量 QA 不回退。
